Uses the same file structure/file names as BanMod and both versions of Among Us Revamped, so if you have been using one of those options you should be able to port your existing start words, disallowed words, and ban/white lists straight over. 

| Command  |  Function  |
| --- | --- |
| /ban <id|name|color> [reason] | bans target player. [reason] is optional |
| /kick <id|name|color> [reason] | kicks target player |
| /unban <id|name|color> | removes target player from your BanList.txt file |
| /addfriend <id> - /deletefriend <id>\n | add/remove target player to your friend list |
| /addmod <id> - /deletemod <id> | add/remove someone from your moderator list |
| /dn <name> - /ddn <name> | add/remove a specific name to the DenyName.txt list | 
| /id |  list player IDs |

DenyName list does not ban specific players, but disallows ANYONE with that name. Tired of Trump, Epstein, and Diddy, etc? Never ever want to see another fake Ssundee or Elegance? this is how you keep them out!

<sub>Untested but should work: the moderator system. Add someone to your moderator list, and they *should* be able to also kick/ban people in your stead.</sub>
